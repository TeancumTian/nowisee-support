# nowisee-support

「原来如此 · Now I See」（近现代科技百科全书）iOS / iPadOS App 的支持页、隐私政策和使用条款，纯静态 HTML（无脚本、无统计），由 GitHub Pages 发布在 https://teancum.me/nowisee-support/ 。

App Store Connect 里的「技术支持网址」填 `https://teancum.me/nowisee-support/`，「隐私政策网址」填 `https://teancum.me/nowisee-support/privacy.html`。改动免费 / 完整版的边界（App 里的 `AtlasCore/Store/Access.swift`）、联系邮箱或数据处理方式时，三个页面要和 App 里的说明一起更新（隐私政策同时改生效日期）。App 源码在私有仓库 TeancumTian/tech-encyclopedia-app，落地页在 https://nowisee.myheartand.me/ 。
